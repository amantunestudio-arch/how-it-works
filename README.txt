GitHub Pages par chalane ke liye:
1. Repo > Settings > Pages > Source: Deploy from a branch > Branch: main, Folder: /docs > Save.
2. Site: https://USERNAME.github.io/REPO/   Dashboard: https://USERNAME.github.io/REPO/#/dashboard/login
3. Dashboard me username, repo, token (Contents: Read and write) daalo. Publish karte hi docs/data update hota hai, site 1-2 min me badalti hai.
Email badalna: docs/config.json me "email" (GitHub par edit kar sakte ho).
Code badalne par: node build.mjs (docs folder dobara banta hai).
